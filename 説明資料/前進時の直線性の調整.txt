picoCar　前進時の直進性の調整 

2026/8/20
picoCarに使用しているSG90-360度タイプはPWMのデューティ比で回転数を決めている。
左右のサーボをそれぞれ逆方向に回転させて前進させている。
さらにサーボ個体差もあり、直進性を確保するためには、デューティ比の調整が必要である。

Mode 1 で前進
Mode 2 で後退　のテストが可能となる


config.pyの

def rigth_duty():
    # 右車輪　前進 , 後退 ,停止
    return 4400,5400,4900

def left_duty():
    # 左車輪　前進 , 後退 ,停止
    return 5350,4450,4900


に初期値を設定している。
今回のプログラム(adjustment_run.py)では、左のサーボのデューティ比を調整することとしている
初期値で走らせて、左右どちらに傾くかを確認する。

設定方法
パソコンにてadjust_run.pyをコピーしてmain.pyとしておく
picoCarをパソコンのThonnyとUSB接続してmain.pyとconfig.pyを、picoCarにアップロードする。(この時picoCarのスイッチはoff)
USBを抜き、電池を入れて、picoCarのスイッチをonにし、BootSwを押すとすると2秒後に前進し8秒後に停止する。

この時、直進すれば初期値のままで良いが、右か左にズレた場合調整が必要となる。

左にズレた場合、左サーボの回転数が右より少ない事となり、右にズレた場合は回転数が右より多いためである。
config.pyの
def rigth_duty():
    # 右車輪　前進 , 後退 ,停止
    return 4400,5400,4900

def left_duty():
    # 左車輪　前進 , 後退 ,停止
    return 5350,4450,4900

の4400,5350を調整する。


この調整を行うことで、若干の誤差が残るが、概ね前進時の直進性が得られる。
